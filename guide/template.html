На главной Claude нажмите New project → назовите, например, FitnessLife. Откройте его и убедитесь, что скилл fitness-tracker доступен внутри проекта. Почему обязательно: сам скилл ничего не помнит между чатами. Память даёт проект — там лежит файл fitness-config.json (добавим на шаге 5). Если что-то пошло не такTroubleshooting

Claude пишет, что не может достучаться до Notion / сетиClaude says it can't reach Notion / the network
Блокировка песочницы. Вернитесь к шагу 1: включите Allow network egress и добавьте домен (api.notion.com для Notion, sheets.googleapis.com + oauth2.googleapis.com для Sheets, *.openfoodfacts.org для авто-КБЖУ) — либо выберите All domains.

‼️ Главное: список доменов фиксируется при старте чата. После изменения откройте новый чат в том же проекте — в текущем правки не подействуют (конфиг к этому моменту лучше сохранить, шаг 5).Sandbox block. Go back to step 1: enable Allow network egress and add the domain (api.notion.com for Notion, sheets.googleapis.com + oauth2.googleapis.com for Sheets, *.openfoodfacts.org for auto-macros) — or pick All domains.

‼️ Key point: the domain list is captured when the chat starts. After changing it, open a new chat in the same project — edits won't apply to the current one (best to save the config first, step 5).
Notion: ошибка 403 / интеграция «не видит» страницуNotion: 403 / the integration "can't see" the page
Интеграции не выдан доступ к странице. Откройте интеграцию на my-integrations → Content access → Private → Top level pages → выберите вашу страницу (шаг 4, пункт 6). Убедитесь, что выбран тот же workspace.The integration wasn't granted access to the page. Open it at my-integrations → Content access → Private → Top level pages → select your page (step 4, item 6). Make sure the same workspace is selected.
При новой сессии Claude просит настроить всё зановоOn a new session Claude asks to set everything up again
Конфиг не сохранён в проект (или назван иначе). Сохраните файл в знания проекта вручную, ровно с именем fitness-config.json (шаг 5), и пишите внутри того же проекта. Имя задаёте вы — по нему скилл находит настройки.The config wasn't saved to the project (or got a different name). Save the file to the project knowledge manually, named exactly fitness-config.json (step 5), and chat inside the same project. You set the name — the skill finds settings by it.
Изменил токен/цели, а Claude использует старые / в проекте два одинаковых файлаChanged token/goals but Claude uses the old ones / two identical files in the project
Две причины. (1) Знания проекта подгружаются в начале нового чата — обновив fitness-config.json, откройте новый чат в проекте. (2) Сохранение часто создаёт дубль вместо замены — оставьте в проекте ровно один fitness-config.json, старый удалите, иначе подхватится устаревший.Two causes. (1) Project knowledge loads at the start of a new chat — after updating fitness-config.json, open a new chat in the project. (2) Saving often creates a duplicate instead of replacing — keep exactly one fitness-config.json in the project and delete the old one, or the stale copy loads.
Настройка прервалась на полпути (например, из-за домена)Setup got interrupted halfway (e.g. a domain issue)
Ничего не потеряно — прогресс сохраняется по ходу. Сохраните текущий fitness-config.json в проект (шаг 5) и откройте новый чат в том же проекте. Claude подхватит сохранённые настройки и продолжит с места остановки (дозапустит создание баз и т.п.) — заново проходить онбординг не нужно.Nothing is lost — progress is saved as you go. Save the current fitness-config.json to the project (step 5) and open a new chat in the same project. Claude picks up the saved settings and resumes where it left off (finishes creating databases, etc.) — no need to redo onboarding.
