# Backend: Local file

Все записи хранятся в одном JSON-файле на диске (или в песочнице claude.ai).
Никакой регистрации и настройки не требуется.

---

## Что это такое

Файл по умолчанию: `fitness-data.json` — **рядом с `fitness-config.json`**
(относительный путь резолвится от папки конфига, а не от текущей директории).
Путь можно переопределить абсолютным значением через конфиг или переменную
окружения `FITTRACK_DATA`.

Структура файла:

```json
{
  "food": [
    {
      "date": "2026-06-07",
      "meal": "lunch",
      "item": "куриная грудка",
      "qty_g": 200,
      "kcal": 330,
      "protein_g": 62,
      "fat_g": 7.2,
      "carbs_g": 0,
      "source": "claude",
      "notes": "",
      "_seq": 1,
      "id": "f000001"
    }
  ],
  "workout": [
    {
      "date": "2026-06-07",
      "type": "strength",
      "exercise": "жим лёжа",
      "sets": 5,
      "reps": 5,
      "weight_kg": 80,
      "duration_min": null,
      "distance_km": null,
      "rpe": null,
      "volume": 2000,
      "notes": "",
      "_seq": 1,
      "id": "w000001"
    }
  ],
  "bodyweight": [
    {
      "date": "2026-06-07",
      "weight_kg": 84.5,
      "notes": "",
      "_seq": 1,
      "id": "b000001"
    }
  ]
}
```

Поля `_seq` и `id` проставляются автоматически при записи — не задавайте их вручную.

---

## Настройка

Минимальный `config-set` для выбора локального бэкенда:

```
python scripts/fittrack.py config-set --patch '{"backend":{"type":"local","local":{"path":"fitness-data.json"}}}'
```

Чтобы указать другой путь:

```
python scripts/fittrack.py config-set --patch '{"backend":{"type":"local","local":{"path":"/my/folder/fitness-data.json"}}}'
```

Альтернатива без изменения конфига — переменная окружения:

```
FITTRACK_DATA=/my/folder/fitness-data.json python scripts/fittrack.py status
```

Файл создаётся автоматически при первой записи (или при `ensure-schema`).

---

## Важно: данные не сохраняются между сессиями claude.ai

> **Критическое предупреждение.** Файл `fitness-data.json` живёт в песочнице
> сессии и **не переживает её завершение автоматически**.

Чтобы ничего не потерять:

1. Держите **оба** файла — `fitness-config.json` и `fitness-data.json` — как
   файлы в **Claude Project** (раздел "Project knowledge").
2. После каждой сессии логирования **пересохраняйте** `fitness-data.json`
   в Project (скачайте или скопируйте содержимое и обновите файл проекта).
3. Если забудете пересохранить — записи за сессию пропадут.

**Для регулярного использования настоятельно рекомендуется облачный бэкенд
(Notion или Google Sheets):** данные хранятся в вашем аккаунте, `fitness-config.json`
достаточно для восстановления доступа.

---

## Резервное копирование

Файл — обычный JSON. Достаточно скопировать его в безопасное место:

- Вручную: скачайте `fitness-data.json` и сохраните локально.
- Автоматически: добавьте файл в git-репозиторий или облачное хранилище.

---

## Миграция на облачный бэкенд

1. Сохраните `fitness-data.json` — он останется архивом ваших данных.
2. Настройте Notion или Google Sheets по соответствующему backend-guide.
3. Смените бэкенд через `config-set` и запустите `ensure-schema`.
4. **Старые записи не мигрируют автоматически** — они останутся только в JSON-файле.
   Если история важна, скопируйте данные вручную или через скрипт.
